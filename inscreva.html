Estilo e animação
Fundo
  • O cursor entra, clica em Inscrever-se, abre o menu do sininho e escolhe Todas, e depois clica no gostei. Desligue o que não quiser.
  • Cole o link do seu canal pra puxar a foto, o nome e os inscritos (precisa de uma chave grátis da API do YouTube).
  • Já vem com fundo transparente (WEBM ou PNG). Se o seu editor não lê transparência, exporte em MP4 com fundo verde e use chroma key.

O navegador não deixa um site ler a página do YouTube direto, então os dados vêm da API oficial do YouTube, que pede uma chave (é grátis):

  1. Entre em console.cloud.google.com e crie um projeto.
  2. Em APIs e serviços › Biblioteca, ative a YouTube Data API v3.
  3. Em Credenciais › Criar credenciais › Chave de API, copie a chave (começa com AIza).
  4. Cole aqui. Ela fica salva só no seu navegador e só é enviada pro próprio Google.

Dica: em Credenciais, restrinja a chave à YouTube Data API v3.
