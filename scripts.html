9 scripts gratuitos para After Effects (CC 2018 ou mais novo). Clique pra baixar o .jsx.

  1. Baixe o .zip (ou o script que quiser).
  2. No After Effects: File › Scripts › Run Script File… e escolha o .jsx.
  3. Pra deixar fixo no menu, copie pra pasta Adobe After Effects › Support Files › Scripts.
  4. O Script Manager vira um painel: copie a pasta inteira pra Scripts › ScriptUI Panels e abra em Window.
  5. Ative Edit › Preferences › Scripting & Expressions › Allow Scripts to Write Files (precisa pro Exportar PNG).
